## Selected projects

### [Sleep Apnea Prediction from EEG](https://github.com/DertMatt24/Apnoea-EEG)

A multimodal machine-learning study combining overnight EEG recordings with patient-level physiological data to predict sleep-apnoea severity.

The project explores EEG preprocessing, wavelet and spectral feature extraction, dimensionality reduction, classical machine-learning models and attention-based neural networks. Patient-level validation is used to prevent data leakage between recordings belonging to the same subject.

**Technologies:** `Python` `PyTorch` `scikit-learn` `Pandas` `NumPy` `SciPy` `Signal Processing`

---

### [AstraLog-HPC](https://github.com/DertMatt24/AstraLog-HPC-2026)

A distributed rule-processing system for validating and analysing high-throughput sensor data on HPC clusters.

The system uses MPI to distribute rule evaluation across multiple processes, supports dependency-aware scheduling and processes simple, stateful, step-difference and correlation rules. The project also includes MQTT-based preprocessing, SLURM execution and Apptainer deployment.

**Technologies:** `Python` `MPI` `SLURM` `Apptainer` `MQTT` `GitHub Actions`

---

### [Associative Memory](https://github.com/lorenzozanizz/associative-memory)

An educational C++ library focused on foundational associative-memory and machine-learning concepts.

The project explores the implementation of learning algorithms and memory models with an emphasis on understandable, reusable and efficient C++ code.

**Technologies:** `C++` `Machine Learning`
